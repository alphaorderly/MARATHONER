# Copilot Project Context and Conventions

## Project Context

This is a React Native mobile app project. The following conventions and preferences should be followed:

-   Use React Native components and styling.
-   Prefer functional components with hooks.
-   Adhere to React Native best practices.

## Conventions

-   **Components**: Use TypeScript for all components.
-   **Naming**: Use PascalCase for component names and camelCase for function names and variables.
-   **Styling**: Use Nativewind v4 for styling components.

## Preferences

-   **Framework**: This project is built using React Native.
-   **Language**: All components and scripts should be written in TypeScript.
-   **Styling Library**: Utilize `Nativewind` and follow the react-native-stylesheet conventions for styling.
